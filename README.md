# sim-utils
Utilities for conducting simulation studies.

# Download

In the future I hope to upload this to pypi. For now pip install
directly from git.

```
> pip install git+https://github.com/HHRI-Transplantation/sim-utils
```

# Usage

Currently contains polars expressions for collapsing abo
categories and calculating the haversine distance between
coordinates.
